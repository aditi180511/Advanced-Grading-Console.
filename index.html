Marks file format guidance

The uploaded Excel file should contain exactly three columns: BITS ID, Course, and Total Marks.

Total Marks must be a whole-number value from 0 to 100. Decimal values are rounded to the nearest integer.

Students who did not appear for the trimester-end examination and are to receive an NC grade should not be included.
